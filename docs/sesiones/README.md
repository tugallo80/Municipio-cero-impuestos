# Fichas de sub-sesión

Cada ficha es la instrucción con la que arranca una sub-sesión. Formato:

- **Objetivo** — qué queda funcionando al final.
- **Antes de empezar** — qué leer, qué tiene que haber hecho el dueño.
- **Tareas** — en orden.
- **Hecho cuando** — criterio de salida verificable (idealmente desde el celular).
- **Cierre** — la sub-sesión anota aquí lo que quedó pendiente y actualiza `docs/plan-maestro.md`.

Rama de trabajo: la que asigne la sesión al crearse. Un PR por sub-sesión.
