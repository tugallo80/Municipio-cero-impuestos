# Textos oficiales del Ministerio de Educación (para pruebas del cronograma)

Textos de aprendizaje oficiales 2025 del Ministerio de Educación de Bolivia, **2.º año de escolaridad de
Educación Secundaria Comunitaria Productiva**, que el dueño consiguió el 8-nov-2026 para EDU.04b.
Son de distribución gratuita ("la venta de este documento está prohibida"); se guarda solo el
**texto extraído** (pdftotext) para no inflar el repo, más una muestra de 12 páginas en PDF
(portada + índice + primer tema de Inglés) para probar la subida de PDF.

| Archivo | Área |
|---|---|
| `2do-secundaria/lengua-extranjera-ingles.txt` | Lengua Extranjera (Inglés) |
| `2do-secundaria/cosmovisiones-filosofia-psicologia.txt` | Cosmovisiones, Filosofía y Psicología |
| `2do-secundaria/artes-plasticas-visuales.txt` | Artes Plásticas y Visuales |
| `2do-secundaria/educacion-musical.txt` | Educación Musical |
| `2do-secundaria/valores-espiritualidad-religiones.txt` | Valores, Espiritualidad y Religiones |
| `2do-secundaria/texto-general-areas-principales.txt` | Texto general: Lengua Castellana, Matemática, Biología-Geografía y Ciencias Sociales. **Índice completo**; el contenido llega solo hasta parte de Matemática (Drive entrega ~200.000 caracteres) |
| `2do-secundaria/muestra-ingles-12-paginas.pdf` | Muestra para probar la carga de PDF |

Cada texto trae un **índice por trimestre** (unidades y temas): sirve para armar el cronograma.
El texto general (25 MB) está en el Drive del dueño; aquí va lo que Drive dejó extraer.
